| Natural break | Next | The fresh session starts from |
| --- | --- | --- |
| the plan is written: `spec.md` with `issues/`, or `analysis.md` for a short run | the first change | the plan |
| a ticket is committed and its file says `Status: done` | the next ticket's claim | that ticket and `spec.md` |
| the run's last commit is in (the last ticket, the one the order named, or the short run's), and what a user sees of it is unverified | the verification of what a user sees, over the committed work | the plan |
| the run's last commit is in, and nothing a user sees is left unverified | `ready-for-host`, with no session for a next ticket | none: the host takes the task on |
| a task without tickets is answered and recorded | the next task | `status.md` |
